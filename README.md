# SEO-карта

Внутренний разбор SEO / AEO / GEO для команды: интерактивная схема, типы клиентов, скрытый спрос, ссылки и площадки, сравнение контент-заводов, свежие данные, ревизия команды SEO-агентов.

Статика без сборки. Страницы – папки с `index.html`, общие стили и шапка – `assets/`. noindex + robots Disallow.
